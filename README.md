# PolyvascularDiseaseAndCancer

This repository contains the SAS programs, R scripts, and supporting resources used for the analyses and manuscript revisions associated with:

Polyvascular atherosclerotic disease and cancer risk in US insurance claims: a retrospective cohort study.

Programs used to create the initial analytic cohort are not included in this repository. The analytic cohort was originally developed as part of a separate research project and contains substantial project-specific data management code that is not directly relevant to the analyses presented in this manuscript.

The materials provided here include all code used to generate the statistical analyses, tables, figures, and revision-related outputs for the current study, assuming access to the analytic cohort dataset described in the manuscript.

Because the study uses licensed administrative claims data, the underlying data cannot be publicly distributed.
